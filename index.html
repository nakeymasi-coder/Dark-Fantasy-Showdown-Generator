Prompt Formula

This guidance belongs before the builder so it helps the user structure the prompt before generation instead of showing up after the work is already done.

Base formula: Hero + weapon + outfit + giant creature + confrontation moment + ruined world + destruction + cinematic lighting + atmosphere + camera + composition + mood + finish + texture detail.
Best results: Keep scale contrast strong, give the creature clear surface detail, and let the environment support the drama instead of feeling random.
Quick Quality Tips
Use one strong hero. This niche looks best when the human figure is isolated against the huge threat.
Pair lighting with the creature. Fire, frost, rot, lightning, smoke, or ash should feel connected to the monster’s presence.
Make the world react. Add broken stone, ash, falling debris, wind, sparks, or torn banners so the scene feels alive.
